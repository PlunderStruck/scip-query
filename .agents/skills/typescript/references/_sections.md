# TypeScript Rule Sections

This index exists so the compiled `AGENTS.md` table of contents can link to stable category anchors while the detailed rules stay in one file per rule.

## 1 Type System Performance

Use these rules for exported APIs, complex generic types, conditional types, recursive types, mapped types, and slow declaration emit.

## 2 Compiler Configuration

Use these rules for `tsconfig.json`, project references, incremental builds, included files, strictness flags, and single-file transpilation.

## 3 Async Patterns

Use these rules for Promise concurrency, loop awaits, unnecessary async wrappers, deferred awaits, and async return typing.

## 4 Module Organization

Use these rules for barrel imports, circular dependencies, type-only imports, dynamic imports, and package type inclusion.

## 5 Type Safety Patterns

Use these rules for `unknown`, type guards, assertion functions, exhaustive checks, const assertions, and nullability.

## 6 Memory Management

Use these rules for closures, timers, listeners, global state, and object metadata caches.

## 7 Runtime Optimization

Use these rules for hot loops, repeated property access, object spread, native collections, native array methods, and string operations.

## 8 Advanced Patterns

Use these rules for branded types, `satisfies`, and template literal types when the project already benefits from advanced type modeling.
