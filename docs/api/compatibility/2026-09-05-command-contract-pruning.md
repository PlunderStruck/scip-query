# Command contract pruning

This change intentionally retires wrapper-candidates, stale-abstractions, complexity-hotspots, reference-neighborhood and reference-reachability from the CLI and public query exports. Their implementation and dedicated tests are removed. Use exact refs/evidence and source review for ownership, complexity/health/review for measured complexity, and refs/call-graph/evidence for typed graph relationships.

Indexed health no longer runs the three retired detectors or returns wrapper, stale-abstraction or synthetic complexity-score fields (including churn-weighted synthetic scores). Context no longer returns duplicate legacy reference-neighborhood, calleeReachability or referenceOwners packets; its referenceDepth option/CLI flag is removed. CallGraph, affected and explicit evidence remain. Final schema revisions are listed below.

These are intentional removals, not compatibility aliases. The command-contract ledger records the producer-level reasons. Additional changes in this pass must be recorded here before updating the API manifest.

Further removals: `extract-candidates`, `similar-chains`, and `self-audit`, including their query exports and package subpaths. Extraction estimates did not establish local flow, path similarity rendered unfiltered paths against filtered scores, and provider agreement did not establish accuracy. The indexed health extraction phase, `extractCount`, `extractExclusions`, and `findings.extractionCandidates` are removed. Use bounded local slices and explicit dependency evidence for the supported facts; use independently checked test cases for accuracy.

Retired `value-flow`, its query export/subpath and its query-service request. It duplicated `evidence --edge dataflow` and misrepresented candidate transfers as only proved flow. Use `evidence --symbol <identity> --edge dataflow --direction both --depth 2 --max-edges 48`. Actual local and interprocedural dataflow providers remain.

Other corrected contracts: `kind-counts` now shares the definition catalog with `by-kind`; malformed kinds and ambiguous fan-in roots are rejected. Coupling rejects missing/ambiguous/same-file pairs and incomplete CLI argument pairs. Hotspot counting units are `referencing-chunks`, not occurrences. Reference locations add an optional `evidence` field distinguishing indexed occurrences, definitions, and source/chunk candidates. Hidden call-graph, hierarchy and bottleneck edge caps are removed. Stats labels distinguish mention rows and database modification time from source freshness.

Further command corrections: dependency graphs include source re-export edges by default; health and baselines retain cycles through entry/barrel files. The separate indexer planning graph remains SCIP-only. `system` includes undocumented definitions and retains each symbol's `relativePath`. `surface` uses one selected-path parameter instead of an unbounded SQL placeholder list. `complexity` rejects ambiguous roots and missing/out-of-range source instead of inventing a low score. `redundant-reexports` uses resolved source declarations, includes re-export consumers, and reports review candidates rather than deletion approval. Signature comparison preserves case and literal whitespace. `not-implemented` no longer hides base stubs solely because subclasses override them. `slice-cohesion` preserves partial flow coverage and candidate uncertainty instead of promoting named gaps to complete coverage.

Also retired `isolated`: it overlapped dead-code classification and caused cleanup totals to count the same candidates twice. Retired `trace` CLI/service request and public trace functions/subpath: it overlapped refs/code/inspect while wrongly allowing universal callsite and absence claims. Context and inspect retain the internal source helper, which now rejects ambiguity/stale definitions and cannot certify these universal claims. The public `queries/evidence` subpath now exposes the same typed graph producer used by the CLI instead of the legacy source composition.

Final revisions in this checkpoint: query-service protocol 22, health report cache 9, source-facts payload 12, TypeScript signatures v2. Import rows expose their evidence origin. Entry points expose observedCallerCount (the old indexedCallerCount label was false for candidate rows). Same-line compiler call bindings require callee token coordinates with encoding conversion; unbound AST matches remain candidates. Inspect preserves candidate call qualifications. Graph projections disclose provider-rejected relationships as incomplete coverage.

Cleanup batches preserve original line coordinates across successive removals. Duplicate body comparison selects exact TS/JS callable offsets, preventing sibling functions on one line from sharing an incorrect body. History scans filter requested files before candidate budgets; documentation scan counts reflect examined docs and retain every stale subject of a selected doc.

The final producer audit also changes these retained contracts:

- Locality output uses `nearestCommonDirectory`, `symbol-observations`, `candidate`, and `no-observed-consumers`. Directory ancestry does not establish conceptual ownership. Ambiguous selectors are rejected.
- Architecture coverage reports unmapped files even without configured boundaries, aggregates every represented file cycle, and marks file-filtered projections as insufficient for global policy conclusions. Scoped projections do not declare unused allowances.
- Similarity uses complete, current callable source, isolates same-line siblings, rejects ambiguous targets, and versions persisted source fingerprints. Similar-files discloses `filtered-dependency-overlap`, uses global popularity under scope, and honors the selected minimum after filtering (default 4, or 1 with a file selector).
- Twin-drift preserves string literals. Its name and token comparison remains a review candidate; the legacy `maxDivergence` field is explicitly the divergence of the closest nonidentical pair, not a maximum over the group.
- Migration vocabulary labels are `shared-vocabulary`, `distinct-vocabulary`, and `unknown`; these do not identify domain subtypes. Comment text cannot masquerade as a historical TypeScript helper declaration.
- Test-quality recognizes assertion APIs rather than counting mock APIs as assertions. Drift does not count an import declaration as use.
- Reindex rejects unknown languages and no longer accepts the unused `--pnpm-workspaces` wrapper option. Health baseline modes are mutually exclusive and emit valid JSON. Private workers reject malformed phase/shard/file arguments before opening the database.
- Auxiliary source augmentation uses NUL-delimited Git paths; Vue augmentation requires one matching definition range and does not guess a same-name target by proximity.
- Printed continuation commands no longer include the closing prose bracket. Continuation reads the saved result even if source changes between pages.
- The architecture Stop hook observes deleted files and preserves quoted/Unicode Git paths. Bounded indexed health output discloses caps on small indexes too.

This changes report and declaration contracts, so existing API consumers must regenerate against the new declaration manifest. Query-service protocol 25, indexed-health cache 11, source-fingerprint payload 2, and Vue augmentation fingerprint 4 invalidate older derived outputs.

Diff-impact now unions every available consumer tier and counts unique consumer files, compares current worktree bytes against the base, preserves Git-quoted paths, and reports `unindexedChangedFiles` even when other files are indexed. A staged version that has been reverted in the current worktree no longer contaminates current-source attribution.
