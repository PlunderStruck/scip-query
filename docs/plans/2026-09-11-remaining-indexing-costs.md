## Existing flow

The reindex coordinator in `src/reindex/index.ts` plans changes through `typescript-incremental-index.ts`. Its affected set includes transitive file consumers. The requester batches that set through the existing watcher mailbox to `TypeScriptIndexServiceHost` and `TypeScriptDocumentEmitter.advance`. The emitter retains a TypeScript program, parsed source nodes and bounded serialized document cache. On edits it replaces the program and retains unchanged documents only when the modified modules' complete export boundaries match. Missing state or changed boundaries currently causes conservative re-emission of the entire requested closure. Existing overlay/blob owners transport verified retained documents; immutable SQLite publication applies actual replacements and updates source metadata before runtime augmentation.

`analysis/runtime-boundaries/graph.ts` collects direct observations, then HTTP propagation, mounts and carrier propagation. `materializeRuntimePhase` validates whole-phase inputs using actual source bytes, indexed fingerprints and exact SQL query results. Each recomputation uses a fresh database reader so warm caches cannot hide inputs. HTTP propagation merges callable summaries through one ordered queue. Carrier propagation first builds body summaries, then derives producer and consumer observations. Adding one HTTP request currently invalidates both whole phases even though the body-summary seeds remain unchanged.

## Comparable mechanisms and ownership

- Extend existing phase-input validation and runtime graph persistence. Do not invent a second cache store or substitute displayed proof spans for consumed inputs.
- Retain ordered summary merging and all unresolved/error outputs. Splitting a computation is valid only when its full inputs and merge semantics are preserved.
- Extend the compiler emitter, symbol-boundary owner, fragment cache and existing publication transport. Source identity, exported types and declaration origins can each change references; direct imports or unchanged declaration text alone are insufficient for reuse.
- Existing retained-publication histories compare real service updates with fresh graphs; storage tests include empty-to-nonempty query invalidation. Reuse those consumers and add distinguishing regressions.
