# Merge-readiness blocker remediation

## Outcome

Make the current exploration, indexing, and cache-lifecycle branch safe to fast-forward into `main`. Existing public consumers receive every feasible compatibility bridge, authoritative contracts describe only current durable state, public command semantics are explicit rather than inferred, repeated worktrees and edits prove bounded cache growth and cleanup, and all repository gates pass from the final tree.

This program does not reopen the intentionally narrow architecture Stop hook or require every stochastic benchmark sample to beat control. The later architecture program explicitly owns the hook, and the held benchmark record already exposes and investigates run variance while establishing aggregate non-inferiority.

## Current path

- The branch is clean, contains `main`, and can fast-forward: it is 129 commits ahead and zero behind. Its remote tracking branch is 45 commits behind local HEAD.
- The public declaration acceptance record classifies removal of `planContext`, its `PlanContext*` types, `diffGate`, and their declaration paths as breaking. `repositoryContext` is the direct replacement for `planContext`, while the workflow-state and blocking-diff subsystems were intentionally retired. The repository policy nevertheless requires a deprecated adapter for one minor release whenever one is feasible (`docs/API_EVOLUTION.md:56-71`; `docs/api/changes/aa13451b53694798.json:121-172,229-286,421-472,529-629`; `src/queries/impact/context.ts:158-427`).
- The product-simplification program deliberately deleted automatic outcome journaling and the tracked lifecycle records, but the durability call-site table still describes outcome events as repository-durable shared history (`docs/plans/2026-08-01-product-simplification.md:41-59,83-90`; `docs/DURABILITY.md:95-127`).
- `CommandAgentContract.semantic` remains optional, and `descriptorSemanticContract()` synthesizes generic analysis or maintenance semantics when it is absent. That contradicts the executable-contract requirement that every public command own one semantic kind (`src/runtime/command-kit/command-descriptor-types.ts:212-240`; `src/runtime/command-kit/command-docs.ts:43-68`; `docs/plans/2026-08-08-navigation-inference-retirement.md:155-169`).
- Cache lifecycle code and focused integration tests exist, but the controlling lifecycle program still marks its repeated disposable-worktree plateau and grace-period aging soak as outstanding (`src/runtime/repository-cache-lifecycle.ts`; `tests/runtime/repository-cache-lifecycle.test.ts`; `docs/plans/2026-08-05-incremental-index-and-cache-lifecycle.md:39-44,92-119`). Current status telemetry reports 235 refreshes in 24 hours, including 184 rebuilds and about 15.6 GB of logical writes, so the soak must distinguish expected development churn from unbounded retention or unnecessary rebuilding.
- `git diff --check main...HEAD` reports Markdown whitespace or EOF defects in six files.

## Open uncertainty

- The exact old `planContext` declaration shape must be recovered from `main` before writing aliases so that the compatibility layer preserves old source contracts rather than merely reusing the old names.
- The set of public descriptors currently relying on synthesized semantics must be enumerated from the registered command list. Hidden internal-only descriptors may retain a separate internal type only if they never enter help, generated documentation, or the public command registry.
- The cache soak must first run against the current implementation. If bytes do not plateau or eligible edits rebuild, use the recorded generation, fingerprint, affected-set, and GC evidence to fix the responsible mechanism; do not weaken the thresholds to certify the current behavior.
