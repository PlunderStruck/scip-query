## How the metrics work (so we don't accidentally make things worse)

**Similarity (`src/queries/similar.ts:138-145`)**: TF-IDF weighted cosine over direct callees. A pair is dropped if `similarity < 0.6` OR `(significantShared.length < 2 && sharedCount < 4)`. So extracting shared logic into ONE helper that both functions call collapses the intersection to `{H}` (size 1) and drops the pair from the report.

**Extract candidates (`src/queries/extract-candidates.ts`)**: Functions with `≥ 15 LOC` and `≥ 5 callees` containing a callee cluster `≥ 3` whose members are not used elsewhere in the function get flagged. Extracting that cluster eliminates the candidate.

**Drift layer rule (`src/queries/drift.ts:196-227`)**: Counts `layerA → layerB` edges across the whole codebase. Edges with `count ≤ 2` are flagged. `getArchitecturalLayer` (`drift.ts:229-242`) groups by `parts[0]/parts[1]` for top-level dirs (so `src/reindex/install.ts` is in layer `src/reindex`). The single `src → src/reindex` edge from `src/scip-cli.ts` is the violation.

## Conventions found in the codebase

- **Helper placement**: Pure utility helpers without DB or scope dependencies live in top-level `src/` files (`src/symbol-parser.ts`, `src/source-text.ts`, `src/gitignore-filter.ts`). Source: `scip-query files 'src/*.ts'`.
- **Per-query helpers**: Helpers used by exactly one query module live as non-exported functions in that module (e.g. `loadKindRows` in `by-kind.ts:186`). Source: `scip-query symbols src/queries/by-kind.ts`.
- **Per-query SHARED helpers**: When two query modules need the same helper, it goes into `src/query-support.ts` (e.g. `getDefinitionsForFile`, `getAllDefinitions`, `buildCalleeMap`, `getResolvedReferenceSites`). Source: `scip-query symbols src/query-support.ts`.
- **AST query helpers**: AST-level helpers live in `src/ast.ts` (e.g. `compileQuery`, `getCallableSites`, `getCallSites`). Source: `scip-query symbols src/ast.ts`.
- **Source parsing helpers**: Per-language source-text parsers live in `src/source-analysis.ts`. Source: `scip-query symbols src/source-analysis.ts`.
- **Cache pattern (AST)**: Each AST helper holds a `WeakMap<Tree, T[]>` (e.g. `CALLABLE_CACHE`, `CALLSITE_CACHE`). After parse, lookup cache, compute, store, return. Source: `scip-query code 'src/ast.ts:201-227'`.
- **Tests**: Behavior tests live in `tests/*.test.ts` and use `tests/fixtures/*` indexes. CLI surface tests in `cli-contract.test.ts`. Health-specific tests in `debloat-health.test.ts`. Source: `ls tests/`.
